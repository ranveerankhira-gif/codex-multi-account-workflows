# 安全与权限

- **读取**：只读取命令行显式指定的来源/目标 Codex 根目录、选中会话、对应项目状态和对话明确引用的文件。不会从 `CODEX_HOME` 或脚本位置猜测账号目录。自然语言发现只扫描指定来源账号。
- **写入**：`recover` 与 `handoff-out` 必须显式提供一个新中立目录。它必须位于账号目录、项目、Skill 和 Git 仓库之外，且路径不得经过符号链接或 Junction。失败清理只作用于带精确兄弟所有权标记、由本次操作新建的目录；不改 Codex 数据库、会话、认证或账号配置。
- **包内代码**：Schema 9 不携带可执行接收器。验证与接收必须使用目标账号本机已安装并审查的 Skill 脚本；旧包中的 `RECEIVER_TOOL.py` 只作为普通字节验证，禁止执行。
- **项目和附件**：Git diff 不嵌入二进制补丁内容；文本 diff、项目路径和文件清单会做凭据模式扫描。引用文件只复制可 UTF-8 检查的文本和可用 Windows OCR 检查的 PNG/JPEG/GIF/WebP；其他二进制类型标记为 `unsupported`，不会复制，也不会自动返回 `ready`。
- **网络与凭据**：不联网、不上传、不切换登录账号、不读取浏览器资料或环境变量凭据。疑似密钥、无法离线核验的图片、MIME 与文件头不一致或 OCR 覆盖不完整都会阻断导出。凭据扫描是模式检测，不能证明不存在所有秘密。
- **费用**：不调用付费服务，不下载模型，不消耗云端额度。
- **确认边界**：只读发现仍需显式调用和来源账号目录；创建接力包、继续原任务或交给另一账号均需当前用户明确指令。历史授权不自动延续，登录、发布、删除、付费和外部发送需另行确认。
